## Sobre Este Proyecto

Este repositorio contiene el código fuente de mi **portafolio y blog personal**, construido con tecnologías modernas:

- **[Astro](https://astro.build/)** — Framework web de alto rendimiento
- **React** — Componentes interactivos
- **NexusCanvas** — Fondo interactivo de múltiples partículas y constelaciones
- **Tailwind CSS v4** — Estilos utility-first
- **Dark Mode** — Tema oscuro automático
- **Responsive** — Diseño adaptable a todos los dispositivos
- **Blog con Markdown** — Sistema de contenido basado en archivos `.md`

### Comandos

```bash
# Instalar dependencias
npm install

# Servidor de desarrollo
npm run dev

# Build de producción
npm run build

# Preview del build
npm run preview
```
