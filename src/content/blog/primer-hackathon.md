# Mi primer Hackathon

Este semestre tuve la oportunidad de participar en mi primer Hackathon, en este Hackathon estuvimos trabajando en un proyecto que consistía en aplicar la tecnología de Open Payments de Interledger. 

## Características principales de nuestra página web

- Sistema para que los artesanos puedan ofrecer y vender sus productos
- Sistema basado en React
- Implementación de la API de Open Payments de Interledger
- Sistema para permitir comprar productos desde la página 
- Sistema para permitir las donaciones 

## Desafíos enfrentados

El mayor desafío fue coordinar el trabajo en equipo y llevar a cabo el desarrollo del sistema con la API de Open Payments de Interledger.

## Resultados

Logramos cumplir con el desarrollo del proyecto y obtuvimos una mención honorífica por el trabajo realizado.
